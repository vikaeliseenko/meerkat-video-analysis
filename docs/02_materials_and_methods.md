# Материалы и методы

## Автоматизированный анализ видеоматериала поведения сурикатов

В качестве исходного материала использовали видеозапись `IMG_1561.MP4`, содержащую наблюдение за поведением сурикатов в вольерной среде. Продолжительность записи составила 530,845 с, частота кадров - 24,985 кадра/с, разрешение - 1280x720 пикселей, общее число кадров - 13 263. Для подготовки обучающей выборки из видео были извлечены 531 статичный кадр с частотой 1 кадр/с.

Для детекции животных была подготовлена предварительная pseudo-разметка. На первом этапе потенциальные положения сурикатов выделялись методом вычитания фона MOG2 с последующей морфологической очисткой маски. Полученные области фильтровались по площади, высоте, ширине и соотношению сторон. Для участков видео, где животные находились в повторяющихся визуально стабильных позициях, дополнительно использовались широкие якорные зоны. В результате было сформировано 603 ограничивающих рамки; 424 кадра вошли в обучающую часть, 107 кадров - в валидационную, 186 кадров не содержали рамок. Разметка сохранена в формате YOLO.

Дообучение выполнялось на архитектуре YOLOv8n с одним классом `meerkat`. Использовались предобученные веса YOLOv8n, размер входного изображения 512 пикселей, batch size 16, 35 эпох обучения, вычисления выполнялись на CPU. Валидационная часть использовалась для технической оценки качества детекции на pseudo-разметке; она не рассматривалась как независимая экспертная проверка.

После обучения модель применялась к исходному видео с частотой анализа 3 кадра/с. Для сопровождения обнаруженных объектов использовался трекер ByteTrack. Для каждой рамки рассчитывались координаты центра, скорость смещения центра между соседними анализируемыми кадрами и степень перекрытия с другими рамками. Дополнительно была задана предварительная зона интереса, соответствующая предполагаемой зоне обогащения среды: `x1=560`, `y1=530`, `x2=735`, `y2=675`. Эта зона имеет статус предварительной и требует сверки с экспериментальным протоколом.

Поведение классифицировалось правиловым алгоритмом. При отсутствии детекций фиксировалась категория `out_of_view`. При перекрытии рамок животных регистрировался `social_contact`. Если центр рамки находился в зоне обогащения при низкой или умеренной скорости, событие относилось к `olfactory_interest`. Высокая скорость смещения классифицировалась как `active_movement`, низкая скорость - как `inactive`, промежуточное движение вне зоны обогащения - как `exploratory`. События агрегировались по 30-секундным интервалам, после чего формировались этограмма, сводные таблицы, графики распределения категорий поведения, график динамики поведения во времени и аннотированное видео.

Так как исходная разметка была получена автоматически, результаты следует рассматривать как предварительный компьютерный анализ видеоматериала. Для включения в строгий научный отчёт рекомендуется вручную проверить часть рамок, уточнить координаты зоны обогащения и провести экспертную валидацию классификации поведения.
