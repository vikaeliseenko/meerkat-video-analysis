Автоматизированный видеоанализ поведения сурикат

Проект для регистрации поведения сурикат при ольфакторном обогащении среды: извлечение кадров, разметка, обучение модели, распознавание животных и формирование этологической таблицы.

Кратко о проекте

Система выделяет сурикат на кадрах, сохраняет координаты рамок, оценивает положение животных и формирует таблицы для анализа поведения.

Графики обучения

Алгоритм

  1. Загрузка видеоматериала.
  2. Извлечение кадров с заданным временным шагом.
  3. Разметка сурикат ограничивающими рамками в формате YOLO.
  4. Формирование обучающей и проверочной выборок.
  5. Обучение модели YOLO для класса meerkat.
  6. Детекция животных на кадрах и видео.
  7. Формирование таблицы координат рамок.
  8. Классификация поведения по положению, зоне обогащения и форме рамки.
  9. Агрегация результатов в этологическую таблицу.
