# Алгоритм анализа видеоматериала IMG_1561

## Назначение

Алгоритм предназначен для автоматизированного выделения сурикатов на видеоматериале, последующего трекинга животных и предварительной классификации поведенческих событий. В текущей версии он является прототипом: детектор дообучен на pseudo-разметке, а поведение определяется набором прозрачных правил.

## Последовательность обработки

1. Загрузка исходного видео `videos/IMG_1561.MP4`.
2. Извлечение кадров с частотой 1 кадр/с для подготовки обучающей выборки.
3. Создание обзорных контактных листов для контроля качества кадров.
4. Генерация pseudo-разметки сурикатов:
   - выделение движущихся областей методом MOG2;
   - морфологическая очистка маски;
   - фильтрация кандидатов по площади, размеру и соотношению сторон;
   - добавление якорных областей для повторяющихся видимых позиций животных;
   - сохранение рамок в YOLO-формате.
5. Разделение датасета на train/val в соотношении примерно 80/20.
6. Дообучение YOLOv8n на одном классе `meerkat`.
7. Анализ видео дообученной моделью:
   - выбор кадров с частотой 3 кадра/с;
   - детекция сурикатов;
   - трекинг с ByteTrack;
   - расчёт центра рамки, скорости смещения и пересечения рамок.
8. Классификация поведения по правилам:
   - `out_of_view` - сурикат не обнаружен на анализируемом кадре;
   - `social_contact` - рамка животного пересекается с рамкой другого животного;
   - `olfactory_interest` - центр рамки находится в предварительно заданной зоне обогащения при низкой/умеренной скорости;
   - `active_movement` - высокая скорость смещения центра рамки;
   - `inactive` - низкая скорость смещения;
   - `exploratory` - промежуточная активность вне зоны обогащения;
   - `uncertain` - рамка слишком мала или ненадёжна.
9. Агрегация событий по 30-секундным интервалам.
10. Построение графиков, таблиц и аннотированного видео.

## Псевдокод

```text
video = open(IMG_1561.MP4)
frames = extract_frames(video, fps=1)
boxes = motion_segmentation(frames)
boxes = filter_boxes(boxes)
boxes = add_anchor_boxes(boxes)
save_yolo_dataset(frames, boxes)

model = load_pretrained_yolov8n()
model.train(dataset, epochs=35, imgsz=512)

for frame in sample(video, fps=3):
    detections = model.track(frame, tracker=ByteTrack)
    if detections are empty:
        save_event("out_of_view")
    else:
        for detection in detections:
            center = bbox_center(detection)
            speed = distance(center, previous_center(track_id))
            overlap = count_overlaps(detection, other_detections)
            in_zone = center_inside_enrichment_zone(center)
            behavior = classify(speed, overlap, in_zone)
            save_event(track_id, behavior, center, speed)

aggregate_events(bin_size=30 sec)
make_tables_and_plots()
```

## Ограничения алгоритма

Текущая версия не различает индивидуальных животных биологически: `track_id` является временным идентификатором трекера и может сбрасываться или меняться при перекрытиях. Проценты и длительности в таблицах отражают записи-события, а не точное индивидуальное время каждого животного. Зона обогащения задана предварительно по изображению и должна быть сверена с протоколом эксперимента.
