# Краткая методика анализа видео IMG_1561

## Цель

Целью работы было получить воспроизводимый протокол автоматизированного анализа поведения сурикатов по видеоматериалу `IMG_1561.MP4`: выделить животных на кадрах, дообучить модель детекции, выполнить трекинг и получить предварительную сводку поведенческих категорий.

## Исходный материал

Использовалось одно видео продолжительностью 530,845 с, разрешением 1280x720 пикселей и частотой 24,985 кадра/с. Из видео было извлечено 531 изображение с частотой 1 кадр/с для подготовки обучающей выборки.

## Подготовка разметки

Так как ручной разметки не было, была создана предварительная pseudo-разметка. Потенциальные положения сурикатов определялись методом вычитания фона MOG2, затем области фильтровались по площади, размеру и форме. Для повторяющихся видимых позиций животных дополнительно использовались вручную заданные якорные зоны. Всего было получено 603 ограничивающие рамки: 424 кадра вошли в обучающую часть, 107 кадров - в валидационную.

## Дообучение модели

Для детекции использовалась модель YOLOv8n с одним классом `meerkat`. Обучение выполнялось на предобученных весах YOLOv8n в течение 35 эпох, размер входного изображения составлял 512 пикселей, batch size - 16. Итоговая модель сохранена в файле `runs/detect/IMG1561_meerkat_detector/weights/best.pt`.

## Анализ поведения

После обучения модель применялась к исходному видео с частотой анализа 3 кадра/с. Для сопровождения обнаруженных животных использовался ByteTrack. Для каждой детекции рассчитывались координаты центра рамки, скорость смещения между соседними кадрами и перекрытие с другими рамками. Поведение классифицировалось по правилам:

- `inactive` - низкая скорость смещения;
- `active_movement` - высокая скорость смещения;
- `exploratory` - промежуточное перемещение;
- `social_contact` - пересечение рамок нескольких животных;
- `olfactory_interest` - нахождение в предварительно заданной зоне обогащения;
- `out_of_view` - отсутствие обнаруженных животных в кадре.

## Выходные материалы

В результате были получены таблицы `IMG1561_raw_frame_results.csv`, `IMG1561_ethogram_table.csv`, `IMG1561_behavior_event_summary.csv`, графики распределения поведения и динамики по 30-секундным интервалам, траектории центров детекций, а также аннотированное видео `IMG1561_annotated_video.mp4`.

## Ограничения

Результаты являются предварительными, поскольку модель обучалась на pseudo-разметке одного видео. Временные ID трекера не являются устойчивыми индивидуальными номерами животных. Для строгих научных выводов необходимо вручную проверить часть разметки, уточнить зону обогащения и провести экспертную валидацию классификации поведения.
